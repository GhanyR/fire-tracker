# Fire Tracker design exploration

Build four interactive, reversible concepts for a side-by-side user choice. The currently selected production dashboard remains the default; exploration is a separate public view.

- A / Atlas: warm editorial cartography, restrained labels, generous space.
- B / Vector: dark monitoring console, time and UAV context in compact rails.
- C / Ember: cinematic terrain, strong warm typography and a simple playback focal point.
- D / Field: clear blue/white field workspace, large practical controls and readable observations.

Compare all four on the same public NASA observation snapshot, geographic scope, time window and illustrative UAV fleet. No actual drone position, endpoint, token or personal location enters comparison or shares. Distinguish thermal detections from confirmed incidents and date the source. All concepts support region selection, time playback, 2D/3D, UAV preview, observation selection and a source-based report. An optional favorite is local only and does not apply a design to the default dashboard.

Deliver a public comparison URL, individual previews and reviewable open-source branches. Use the existing React/MapLibre app, no extra services or paid assets.
